# Sistema de Inventario
Aplicación web robusta para la gestión y control de inventarios, stock en tiempo real, catálogo de productos y transacciones de venta orientada a pequeñas empresas.

## Contexto
Las pequeñas empresas suelen depender de hojas de cálculo manuales propensas a errores humanos, pérdida de trazabilidad en las existencias y desfases de stock físico vs. registrado. Desarrollé este sistema para proporcionar una solución centralizada, consistente y accesible que automatice el ciclo de vida del inventario, desde el ingreso de mercancía hasta el reporte de ventas diarias.

## Decisiones técnicas
- **Por qué Spring Boot y no Node.js:** Se priorizó el tipado estático, la solidez transaccional con `@Transactional` en operaciones concurrentes de stock y la madurez del ecosistema de Spring (Spring Security, Spring Data JPA) para garantizar consistencia ACID en la base de datos PostgreSQL.
- **Cómo manejé la seguridad y autenticación:** Implementé un flujo stateless con **Spring Security** y tokens **JWT (JSON Web Tokens)** con roles de usuario (Administrador, Cajero, Bodeguero). Las contraseñas se almacenan hasheadas con BCrypt y las rutas críticas de la API están protegidas a nivel de método con anotaciones de autorización.
- **Cómo estructuré la arquitectura backend:** Separación estricta por capas:
  - *Controllers:* Endpoints REST limpios documentados con anotaciones OpenAPI 3.0 / Swagger.
  - *Services & DTOs:* Lógica de negocio desacoplada de las entidades JPA mediante mapeo de objetos de transferencia de datos.
  - *Repositories:* Consultas optimizadas con Spring Data JPA y manejo de índices en PostgreSQL para búsquedas de alta frecuencia (código de barras, SKU).
- **Cómo resolví el empaquetado y portabilidad:** Dockerización completa de la solución en multi-stage build, aislando la aplicación Spring Boot y la base de datos PostgreSQL mediante Docker Compose con variables de entorno parametrizadas.
