# Sistema Académico Escolar
Aplicación móvil multiplataforma orientada a docentes, estudiantes y administradores para el control de calificaciones, asistencias y reportes académicos.

## Contexto
Las instituciones educativas con infraestructura descentralizada sufren demoras significativas en la consolidación de notas bimestrales, duplicidad en listas de asistencia física y falta de visibilidad oportuna para acudientes y directivos. El proyecto se concibió para digitalizar la captura de información directamente desde el aula mediante dispositivos móviles, con sincronización segura hacia una base de datos central.

## Decisiones técnicas
- **Por qué Flutter y no desarrollo nativo por separado:** Se requería entregar una aplicación funcional tanto para Android como iOS manteniendo una sola base de código en Dart. Flutter permitió optimizar el ciclo de entrega y asegurar un rendimiento de 60fps con widgets nativos compilados.
- **Cómo estructuré la arquitectura de la app:** Implementé un patrón por capas limpio (Clean Architecture adaptada a Flutter) con separación clara:
  - *Data layer:* Fuentes remotas (HTTP client con interceptores para inyección automática de token Bearer) y modelos con serialización JSON segura.
  - *Domain/State layer:* Gestión de estado reactiva para el control de ciclos de vida, manejo de caché de sesión y validación de reglas de evaluación académica.
  - *Presentation layer:* Vistas modulares reutilizables y formularios con validación en tiempo real para el ingreso rápido de notas.
- **Cómo resolví la integración y manejo de fallas de red:** Dado que la cobertura de red en colegios puede ser inestable, se diseñó una estrategia de resiliencia con manejo explícito de excepciones HTTP, timeouts y reintentos, evitando bloqueos en la interfaz de usuario.
- **Cómo estructuré el modelo de datos relacional:** En MySQL se normalizó el esquema de datos (estudiantes, asignaturas, periodos lectivos, matrículas y registros de notas) garantizando integridad referencial mediante claves foráneas y restricciones `UNIQUE` para evitar notas duplicadas por periodo.
